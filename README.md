# University Database Starter

A small relational database for managing a university using SQLite.

## What's included
- `university.db` — ready-to-use SQLite database with sample data
- `schema.sql` — table definitions and relationships
- `sample_data.sql` — example records
- `queries.sql` — useful example queries
- `create_database.py` — recreate the database from the SQL files

## Tables
- departments
- programs
- students
- instructors
- courses
- course_offerings
- enrollments
- classrooms
- class_sessions
- payments

## How to use
1. Extract the ZIP.
2. Open `university.db` with DB Browser for SQLite, SQLiteStudio, or another SQLite-compatible tool.
3. To recreate the database, run `python create_database.py` (Python 3 required).

This is a starter database, not a complete student information system. Sample records are fictional.
